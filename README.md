## Development with Local MongoDB Server

If you are making use of a mongoDB server locally you need to initialize a replica set in order to use transactions. You can do this by running the following command in your terminal:

```bash
# Install run-rs globally
npm install run-rs -g

# Initialize a replica set using your local mongoDB server
run-rs --mongod --host 127.0.0.1 --shell --keep --portStart  27000

```

You would need to update the `MONGO_URI` in your `.env` file to the one generated by `run-rs`. Ensure to add the `?replicaSet=rs` to the end of the URI.

## Stripe Webhook Locally

-   Download and install [Stripe CLI](https://stripe.com/docs/stripe-cli)
-   Run

```cmd
stripe login --api-key sk_test_xxxxx...xxxxx

stripe listen --forward-to localhost:8080/webhooks/stripe
```
